# Чанки: тренажёр английских выражений для Android

Приложение-оболочка вокруг одной страницы `app/src/main/assets/index.html`.
Работает без сети и без аккаунтов, прогресс хранится на телефоне.

## Как получить APK

1. Создайте на GitHub новый репозиторий (можно приватный) и загрузите в него
   содержимое этой папки, включая скрытую папку `.github`.
2. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама после
   загрузки; если нет, нажмите **Run workflow**.
3. Через несколько минут откройте **Releases** → **latest** и скачайте
   `chunks.apk`. Это можно сделать прямо с телефона.
4. При установке Android попросит разрешить установку из этого источника.

## Как обновить содержимое

Замените `app/src/main/assets/index.html` новой версией тренажёра и загрузите
изменение в репозиторий: APK пересоберётся. Подпись у всех сборок одна
(`keystore/debug.keystore`), поэтому новая версия ставится поверх старой и
прогресс сохраняется.

## Что важно знать

- Ключ подписи лежит в репозитории открыто. Для личного приложения это
  нормально; для публикации в Google Play нужен отдельный закрытый ключ.
- Минимальная версия Android: 8.0.
